# NursePrepHub

The ultimate free nursing study platform — 21 interactive tools for nursing students.

## Features
- 8 animated lessons (Body Systems, EKG, RAAS, IV Solutions, F&E, Insulin, ABG, Circulation)
- 4 pharmacology tools (Cardiac Meds, Code Blue game, Med Flashcards, Disease Flashcards)
- 4 practice tools (Med Math, NCLEX Prep, Body Systems Quiz, Coach Quest)
- 2 reference tools (Reference Library, Care Plan Generator)
- Study Planner with calendar, tasks, and syllabus import
- AI-powered tutoring via Claude API proxy

## Setup
```bash
npm install
ANTHROPIC_API_KEY=your-key-here npm start
```

## Deploy on DigitalOcean App Platform
1. Push to GitHub
2. Connect repo in DigitalOcean App Platform
3. Set environment variable: `ANTHROPIC_API_KEY`
4. Deploy
